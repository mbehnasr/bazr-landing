## آنچه عمداً نیامده — `NEEDS-REVIEW: مرجع تغذیه`

طبق قانون ۴ قانون‌نامه، این‌ها تا تأیید مرجع تغذیه روی صفحه نمی‌آیند:

- «می‌دونیم سیگار یا الکل بهمون آسیب می‌زنه.» (هایلایت ۱)
- «چون وقتی بدن از تعادل خارج می‌شه، … پیچیده‌تر می‌شن.» (هایلایت مسیر بذر، اسلاید ۲)
- «رژیم تخصصی تغذیه بخشی از مسیر سبک زندگی بذر هست…» (سؤال اول؛ بقیه‌ی جواب آمده)
- کل سؤال «آیا بذر برای کاهش وزن هم استفاده می‌شه؟»
- CBT و ACT از فهرست رویکردها

## چیزهایی که agent اضافه کرد و باید بازبینی شوند

- نام مرحله‌ها در بخش متد (Contemplation، Preparation، Action، Maintenance) کنار چهار جمله‌ی هایلایت ۳. Precontemplation نیامده است.
- نمودار بالای صفحه نمایشی است و عدد ندارد؛ جمله‌ی «سه روز انجامش ندادی. چی تغییر کرد؟» از نمونه‌های لحن برندبوک است.
- عنوان کوتاه چهار قدم «مسیر تو» (دیدن الگوها، تصویر واضح‌تر، …) و برچسب «تنش آشنا» بالای بخش دوم.
- دکمه‌ی ماهانه/سالانه و سه کارت قیمت فقط فرض‌اند.

## ویدئوی پس‌زمینه‌ی نمای اول

ویدئوی فعلی **موقت** است و فقط برای آزمایش آمده: «Contemplative young woman in park» از [Coverr](https://coverr.co/license). استفاده‌ی تجاری آزاد است و ذکر منبع لازم نیست. فایل را جدا نفروشید و بازنشر نکنید.

برای گذاشتن ویدئوی خود بذر، همین دو فایل را با همین نام عوض کنید:

| فایل | چیست |
|---|---|
| `assets/hero.mp4` | ویدئو: H.264، بدون صدا، ۱۰ تا ۱۵ ثانیه، ترجیحاً زیر ۳ مگابایت |
| `assets/hero-poster.jpg` | فریم اول ویدئو؛ تا ویدئو برسد و برای کسی که «کاهش حرکت» را روشن کرده، همین دیده می‌شود |

ساختن هر دو از یک فایل خام (فشرده‌سازی، حذف صدا، و حلقه‌ی بی‌پرش با محو شدن ثانیه‌ی آخر در ثانیه‌ی اول):

```sh
D=$(ffprobe -v error -show_entries format=duration -of csv=p=0 raw.mp4)
ffmpeg -i raw.mp4 -filter_complex "[0:v]split[x][y];[x]trim=start=1:end=$D,setpts=PTS-STARTPTS,fps=25[a];[y]trim=0:1,setpts=PTS-STARTPTS,fps=25[b];[a][b]xfade=transition=fade:duration=1:offset=$(echo "$D - 2" | bc),scale=1280:720,format=yuv420p[v]" \
  -map "[v]" -an -c:v libx264 -preset slow -crf 25 -movflags +faststart assets/hero.mp4
ffmpeg -i assets/hero.mp4 -frames:v 1 -q:v 3 assets/hero-poster.jpg
```

متن روی ویدئو سمت راست است (در انگلیسی سمت چپ) و یک لایه‌ی تیره زیرش خوانایی را نگه می‌دارد. ویدئویی بهتر جواب می‌دهد که سوژه‌اش وسط یا سمت مقابل متن باشد و حرکت آرامی داشته باشد.

ویدئو بی‌صدا و در حلقه پخش می‌شود و دکمه‌ی توقف دارد. وقتی از صفحه بیرون برود، متوقف می‌شود. برای کسی که «کاهش حرکت» یا «صرفه‌جویی در داده» را روشن کرده، اصلاً پخش نمی‌شود.
