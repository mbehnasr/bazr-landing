- **پالت این صفحه از برندبوک ۱.۱ نیست.** ADR-0008 برندبوک ۱.۱ را مرجع هویت بصری کرده؛ این نسخه یک آزمایش است. اگر تیم این جهت را نگه دارد، یا پالت به برندبوک برمی‌گردد یا Owner پروژه تصمیم تازه ثبت می‌کند.
- **لوگو دست نخورده است.** نشان اصلی و جوانه‌ها همان فایل‌های تیم‌اند؛ فقط زمینه‌شان شفاف شده. رنگشان تغییر نکرده و روی زمینه‌ی تیره نیامده‌اند (برندبوک ۱.۱، قواعد لوگو).
- **فونت فارسی همان Vazirmatn است.** واژه‌های مفهومی انگلیسی (TTM، Behavior Change، Lifestyle Coaching، …) طبق ADR-0007 داخل متن فارسی می‌مانند و با Newsreader ایتالیک از بقیه‌ی متن جدا می‌شوند.

## آنچه عمداً نیامده — `NEEDS-REVIEW: مرجع تغذیه`

طبق قانون ۴ قانون‌نامه، این‌ها تا تأیید مرجع تغذیه روی صفحه نمی‌آیند:

- «می‌دونیم سیگار یا الکل بهمون آسیب می‌زنه.» (هایلایت ۱)
- «چون وقتی بدن از تعادل خارج می‌شه، … پیچیده‌تر می‌شن.» (هایلایت مسیر بذر، اسلاید ۲)
- «رژیم تخصصی تغذیه بخشی از مسیر سبک زندگی بذر هست…» (سؤال اول؛ بقیه‌ی جواب آمده)
- کل سؤال «آیا بذر برای کاهش وزن هم استفاده می‌شه؟»
- CBT و ACT از فهرست رویکردها

## چیزهایی که agent اضافه کرد و باید بازبینی شوند

- نام مرحله‌ها در بخش متد (Contemplation، Preparation، Action، Maintenance) کنار چهار جمله‌ی هایلایت ۳. Precontemplation نیامده است.
- نمودار بالای صفحه نمایشی است و عدد ندارد؛ جمله‌ی «سه روز انجامش ندادی. چی تغییر کرد؟» از نمونه‌های لحن برندبوک است.
- عنوان کوتاه چهار قدم «مسیر تو» (دیدن الگوها، تصویر واضح‌تر، …).
- دکمه‌ی ماهانه/سالانه و سه کارت قیمت فقط فرض‌اند.

## ویرایش

```sh
python3 -m http.server 8000
# http://localhost:8000
```
